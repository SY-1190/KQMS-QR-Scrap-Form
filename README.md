# KQMS 공정부적합 신고

QR 스캔으로 시작하는 모바일 공정부적합 신고 운영 Form입니다.

운영 사이트: https://sy-1190.github.io/KQMS-QR-Scrap-Form/

## 운영 범위

- 비공개로 발급된 현장 운영 QR 촬영 및 Cloudflare 사람 확인을 통과한 경우에만 Form 진입
- QR 검증 후 10분 동안 유효한 1회성 접수권 발급
- 발생일 우선 입력과 작성자·작성 팀/부서 필수 입력
- 운영 기준정보의 실제 발생 공정 목록 조회 및 직접 선택
- 운영 부서·협력업체를 합친 실제 작성 팀/부서 목록 조회 및 선택
- 운영 기준정보의 실제 품번·품명·모델·고객사 통합검색과 검색 실패 시 수기작성
- 검색 팝업에서 여러 품번 선택 후 모델·고객사 자동입력
- 수기 품번의 모델·고객사 선택입력
- 여러 품번 추가 및 품번별 호기·EA 수량 입력
- 자진신고 또는 보물찾기 선택
- 수정 또는 폐기 처리 구분 선택
- 수정 선택 시 이동 기준 설명 표시
- 폐기 선택 시 처리 구분 바로 아래에서 적치 장소와 KHMDS 실제 공정 진행 사항 복수 선택
- 실제 폐기품 적치 위치 선택 시 해당 위치 사진 표시
- 공정부적합 기본정보 입력
- 휴대폰 기본 카메라로 촬영해 갤러리에 저장한 사진만 Form에서 선택하고, 원본은 유지한 채 전송용 복사본을 긴 변 최대 1,920px·JPEG 품질 82%로 자동 압축
- 입력 내용 최종 확인
- 암호화된 전송 대기열과 KQMS 접수 상태 화면
- 전송 대기·접수 중·자동 재시도·완료·실패 표시와 실패 건 다시 전송
- KQMS 접수 완료 후 카카오톡 채팅방 공유를 최우선 행동으로 안내
- 사진 없이 접수정보 템플릿과 최근 7일 접수 현황 버튼을 카카오톡으로 전달
- 공유 메시지의 최근 7일 접수 현황 링크에서 조회 시점 기준 완료 접수 최대 100건 확인

이 공개 버전은 화면과 입력 흐름 및 KQMS 접수 상태 확인을 위한 테스트본입니다.

- 입력값은 비공개 운영 백엔드에서 형식과 운영 기준정보를 확인한 뒤 암호화된 대기열을 거쳐 KQMS에 전달합니다.
- 일시 장애는 제한된 횟수만 자동 재시도하며 최종 실패 시 접수자가 다시 전송할 수 있습니다.
- KQMS 접수 성공 시 암호화된 제출 본문은 즉시 삭제하고 접수 확인 메타데이터만 보관합니다.
- 선택한 사진은 암호화된 임시 저장소를 거쳐 KQMS에 전달되며 KQMS 저장 성공 후 임시 사진은 삭제됩니다.
- 현재 카카오톡 공유 단계에는 사진을 포함하지 않으며, KQMS에는 기존대로 사진을 최대 5장 전달합니다.
- 최근 접수 목록에는 접수번호·완료 시각·발생일·공정·처리 구분·품번과 EA 수량만 표시하며 작성자·부서·발생 상세내용·사진은 제외합니다.
- 최근 접수 목록은 자동 갱신하지 않고 사용자가 열거나 새로고침할 때만 조회하며, 공유 시 발급된 조회 주소는 7일 후 만료됩니다.
- 카카오톡 공유에는 내부 접수 확인키와 내부 연동 정보가 표시되지 않으며, 접수정보와 최근 7일 접수 현황 버튼만 전달합니다.
- 내부 KHMDS·KQMS 주소, 인증정보와 실제 저장 계약은 포함하지 않습니다.

## 운영 QR 사용 방법

공정에 부착된 운영 QR을 스마트폰 기본 카메라로 스캔합니다.

운영 QR 이미지와 접속 토큰은 공개 저장소에 포함하지 않습니다. 공개 사이트 주소만 직접 열거나 주소를 즐겨찾기로 실행하면 신고서를 작성할 수 없습니다.

정상 QR이면 Cloudflare 사람 확인 후 비공개 운영 백엔드가 10분 동안 유효한 1회성 접수권을 발급합니다. `등록 시작` 버튼을 누르면 정보 입력 화면으로 이동하며, 제출을 완료한 접수권은 다시 사용할 수 없습니다.

운영 QR은 특정 공정을 고정하지 않습니다. 발생 공정, 작성 팀/부서, 폐기품 적치 위치와 위치 사진, 폐기제품 공정진행사항, 품번 통합검색은 접수권이 있는 동안에만 운영 중계 서비스를 통해 조회할 수 있습니다. 품번 검색은 운영 기준정보의 실제 품번·품명·모델·고객사·등록 고객사 별칭을 대상으로 30건씩 표시하고 `더보기`로 다음 30건을 이어서 불러옵니다. 제출 후에는 비밀 확인키로 전송 대기부터 KQMS 완료 또는 실패까지의 상태를 확인합니다.
