# KQMS 스마트 폐기 등록 · 공개 테스트

QR 스캔으로 시작하는 모바일 폐기 등록 Form의 공개 사용자 흐름 테스트입니다.

공개 테스트 사이트: https://sy-1190.github.io/KQMS-QR-Scrap-Form/

## 공개 테스트 범위

- QR 링크 진입 및 식별값 확인
- 폐기 대상 기본정보 입력
- 스마트폰 카메라 촬영 또는 사진 선택
- 입력 내용 최종 확인
- 테스트 접수 완료 화면

이 공개 버전은 화면과 입력 흐름 검토를 위한 프로토타입입니다.

- 입력한 데이터는 서버나 KQMS에 저장되지 않습니다.
- 선택한 사진은 현재 브라우저에서만 미리보기 됩니다.
- 내부 시스템 API, 인증, 데이터 계약은 포함하지 않습니다.

## 테스트 방법

사이트에서 `테스트 QR 스캔`을 선택하거나 주소 뒤에 QR 식별값을 전달할 수 있습니다.

```text
?qr=QR-TEST-001
```

실제 운영 연동은 공개 테스트 피드백으로 화면과 필드를 확정한 후 별도 비공개 환경에서 진행합니다.
