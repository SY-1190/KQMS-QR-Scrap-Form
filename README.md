# KQMS 공정부적합 신고 · 공개 테스트

QR 스캔으로 시작하는 모바일 공정부적합 신고 Form의 공개 사용자 흐름 테스트입니다.

공개 테스트 사이트: https://sy-1190.github.io/KQMS-QR-Scrap-Form/

## 공개 테스트 범위

- 공정에 부착하는 QR 링크 진입 및 식별값 확인
- QR에 연결된 발생 공정명을 자동입력하고 수정 잠금
- 품번 또는 모델 검색과 검색 실패 시 수기작성
- 여러 품번 추가 및 품번별 EA 수량 입력
- 자진신고 또는 보물찾기 선택
- 수정 또는 폐기 처리 구분 선택
- 공정부적합 기본정보 입력
- 스마트폰 카메라 촬영 또는 사진 선택
- 입력 내용 최종 확인
- 테스트 접수 완료 화면

이 공개 버전은 화면과 입력 흐름 검토를 위한 프로토타입입니다.

- 입력한 데이터는 서버나 KQMS에 저장되지 않습니다.
- 선택한 사진은 현재 브라우저에서만 미리보기 됩니다.
- 내부 시스템 API, 인증, 데이터 계약은 포함하지 않습니다.

## 테스트 방법

아래 QR을 PC나 태블릿에 표시한 뒤 스마트폰 기본 카메라로 스캔합니다.

![조립 공정 공개 테스트 QR](docs/process-test-qr.svg)

같은 기기에서 확인하려면 사이트에서 `테스트 QR 스캔`을 선택하거나 아래 쿼리를 사용합니다.

```text
?qr=QR-PROCESS-TEST-ASSEMBLY
```

공개 QR은 테스트 공정 식별값만 포함합니다. 실제 공정 기준정보 조회와 KQMS 연동은 공개 테스트 피드백으로 화면과 필드를 확정한 후 별도 비공개 환경에서 진행합니다.
