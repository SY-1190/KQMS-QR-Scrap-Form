# KQMS 공정부적합 신고 · 공개 테스트

QR 스캔으로 시작하는 모바일 공정부적합 신고 Form의 공개 사용자 흐름 테스트입니다.

공개 테스트 사이트: https://sy-1190.github.io/KQMS-QR-Scrap-Form/

## 공개 테스트 범위

- 어느 위치에서나 동일한 Form을 여는 QR 링크 진입
- 발생일 우선 입력과 작성자·작성 팀/부서 필수 입력
- KHMDS에서 동기화된 실제 발생 공정 목록 조회 및 직접 선택
- KHMDS 부서·협력업체를 합친 실제 작성 팀/부서 목록 조회 및 선택
- 품번 또는 모델 검색과 검색 실패 시 수기작성
- 검색 품번의 모델·고객사 자동입력
- 수기 품번의 모델·고객사 선택입력
- 여러 품번 추가 및 품번별 호기·EA 수량 입력
- 자진신고 또는 보물찾기 선택
- 수정 또는 폐기 처리 구분 선택
- 수정 선택 시 이동 기준 설명 표시
- 폐기 선택 시 처리 구분 바로 아래에서 적치 장소와 공정 진행 사항 복수 선택
- 공정부적합 기본정보 입력
- 스마트폰 카메라 촬영 또는 사진 선택
- 입력 내용 최종 확인
- 테스트 접수 완료 화면

이 공개 버전은 화면과 입력 흐름 검토를 위한 프로토타입입니다.

- 입력한 데이터는 서버나 KQMS에 저장되지 않습니다.
- 선택한 사진은 현재 브라우저에서만 미리보기 됩니다.
- 공개 공정 및 작성 팀/부서 목록 조회를 제외한 내부 시스템 API, 인증, 저장 계약은 포함하지 않습니다.

## 테스트 방법

아래 QR을 PC나 태블릿에 표시한 뒤 스마트폰 기본 카메라로 스캔합니다.

![공통 공개 테스트 QR](docs/process-test-qr.svg)

같은 기기에서 확인하려면 사이트에서 `테스트 QR 스캔`을 선택하거나 아래 쿼리를 사용합니다.

```text
?qr=QR-KQMS-TEST-UNIVERSAL
```

공개 QR은 특정 공정을 고정하지 않습니다. 발생 공정과 작성 팀/부서는 공개용 중계 서비스를 통해 KHMDS에서 동기화된 실제 목록을 사용하며, 나머지 기준정보 조회와 KQMS 저장 연동은 별도 비공개 환경에서 단계적으로 진행합니다.
